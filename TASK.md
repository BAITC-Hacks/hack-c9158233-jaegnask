# TASK.md

## Цель проекта

Построить инструмент для анализа 4-хопового графа внутрибанковских переводов, восстановить финансовую структуру группы, определить роли участников, выделить кластеры и сформировать приоритетный список узлов для проверки AML-аналитиком.

## Данные

- 2248 узлов
- 3119 уникальных направленных рёбер
- 4840 транзакций
- 81 seed-клиент
- период: июль 2026
- только исходящие переводы
- глубина обхода: 4
- минимальная сумма перевода: 5000 KZT

Файлы:
- data/nodes.parquet
- data/edges.parquet
- data/transactions.parquet

## Важное ограничение данных

Граф обрезан на глубине 4. Узлы на depth=4 нельзя автоматически считать конечными получателями, потому что следующие переводы за пределами 4-го колена не наблюдаются.

## Обязательные результаты

Проект должен генерировать три CSV:

1. nodes_roles.csv
   - строка для каждого gid
   - роль узла
   - confidence / role_score
   - cluster_id
   - priority_score
   - evidence с конкретными числами

2. clusters.csv
   - описание каждого кластера
   - размер
   - seed-узлы
   - внутренний оборот
   - ключевые участники
   - гипотеза назначения кластера

3. top_nodes.csv
   - минимум 20 узлов
   - сортировка по priority_score по убыванию
   - объяснение, почему узел приоритетен

## Роли

Допустимые роли:
- consolidator
- transit
- distributor
- terminal
- coordinator
- peripheral

Роли должны определяться объяснимыми правилами, а не непрозрачной моделью.

- priority_score должен быть интерпретируемым
